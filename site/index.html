Built around four answers

Most agents are brilliant and amnesiac. Memento closes the loop — between what happened, what it believes, and what it does next.

🧠memory

Memory with a spine

Lessons with real confidence dynamics: 0.35 start, +0.15 on evidence, −0.30 on contradiction, retired below 0.12. Wrong memories die fast — that's the design.

📐spec

A spec that answers back

Markdown specs with deterministic checkers — paths must exist, scripts must exist, TODOs surface. Consulted on the way in, verified on the way out. No LLM in the checking loop.

🔌plugins

Plugins in ten lines

Drop a .ts file into .memento/plugins/. No build step, no manifest. Every registration returns a disposer — plugins are guests, not residents.

🌐ecosystem

Ecosystem native

MCP in both directions: serve-mcp shares your memory with Claude Desktop and Cursor; declared MCP servers bridge in as tools. Git status, diff-aware commit hints, undo snapshots.

The confidence arc

Disproof weighs more than proof. A fresh lesson dies on its first contradiction; an earned one survives one conflict, dies on the second.
